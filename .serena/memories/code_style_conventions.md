# Code Style and Conventions

## Current State
The project is in very early stage with minimal code. No established conventions yet.

## Python Standards to Follow
- Follow PEP 8 style guidelines
- Use meaningful variable names
- Add type hints where appropriate
- Use docstrings for functions and classes

## Streamlit Specific
- Use st.title(), st.header(), st.subheader() for hierarchical headings
- Use st.caption() for attribution/credits
- Organize code in logical sections/steps
- Use interactive widgets (buttons, radio, tabs) for user engagement
- Use appropriate Streamlit components for data display (tables, charts, metrics)

## Project Requirements
- No sidebar usage (per user specification)
- Use Plotly for visualizations
- Include specific credits:
  - st.caption("Created by Dit-Lab.(Daiki ITO)")
  - st.caption("Supported by Tomoaki ATSUMI")
